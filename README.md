# WL Digital media

Finished, public marketing files (videos and images) for WL Digital's social media posts.
Scheduling tools such as Metricool fetch them from their direct links:

```
https://raw.githubusercontent.com/SiDaMan1/wl-digital-media/main/<path>
```

Everything here is meant to be public. The sources and the tools that render them live in the
private WL_Digital repo (for Merge Realms: `games/merge-realms/marketing/` and
`games/merge-realms/tools/promo-video/`).

## Layout

- `merge-realms/videos/`: the videos, as 9:16 (TikTok, Reels, Shorts) and 16:9 (YouTube, the Facebook feed).
- `merge-realms/images/`: cover images and other stills.

Don't rename or delete a file once a post uses it; add a new file instead.
